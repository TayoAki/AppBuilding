# AppBuilding

An AI mobile-app builder: describe an app in one prompt, and an AI agent plans its screens, then generates a working React Native / Expo app screen by screen. You can edit it visually or by chat, preview it in the browser and on your phone (QR / Expo Go), connect a backend, export the code (zip / GitHub), build Android/iOS binaries and publish it to the web.

**Status:** planning. No application code yet.
